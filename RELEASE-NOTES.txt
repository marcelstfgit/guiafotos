English (US)

GuiaFotos 0.2.0 — preview build for Windows 10/11 x64.
Local organization, face and photo-version grouping, duplicate detection,
editing copies, and Nextcloud backup. Programming contributions are welcome.

Install: download and run GuiaFotos-0.2.0-Setup.exe.
Portable: extract the entire ZIP and run GuiaFotos.exe. Keep Data when updating.

Publication requires automated Windows build, core, model, grouping,
interface, installation, and uninstallation checks to pass.
These checks do not establish accuracy on a representative photo collection
or validate a production Nextcloud server. Executables are not digitally signed.
The attached report records the commit and completed checks for this package.
Application, FFmpeg/x264/dav1d, and ImageMagick/delegate sources are attached.
